# 语文字帖 UI 改版开发说明

日期：2026-09-14
状态：方案待确认；确认前不修改业务代码。
开发分支：`codex/chinese-copybook-ui-refresh`
分支基线：`b73700c`（从 `codex/home-banner-chinese-grades` 创建）

## 1. 背景与目标

当前语文字帖配置页采用四段纵向长表单，功能完整，但页面密度、暖灰色块比例、设置项展开方式与当前首页的主蓝色、轻卡片、图形化入口不够统一。

本次改版目标：

- 沿用 V2 的品牌蓝、语文学科红、白色卡片、原版小墨和现有字体体系。
- 降低首次生成字帖时对“字体、格线、纸张、描红遍数”等参数的理解成本。
- 选择内容后立即展示真实效果预览，让用户在生成前看见结果。
- 默认配置可快速生成；高级设置不阻塞主流程。
- 复用现有教材、古诗、字帖生成、PDF、历史和配额能力，不重做后端排版体系。
- 普通用户所有学科的字帖生成共享每日 3 份配额；会员与网络兜底规则保持现状。
- 语文教材导入一次只允许选择一课，为后续广告解锁方案形成清晰的单课选择节点；本轮不接入广告。

## 2. 设计输入的使用边界

用户提供的新版页面总览是视觉与流程参考，不自动构成功能需求。图中下列内容需按本说明适配：

- “生字详解”“强化练习”等推荐样式不在当前生成参数内，本轮不新增对应生成模式。
- “发送到电脑”当前没有直接发送能力，本轮继续使用准确的“复制打印链接”或“打印链接”文案。
- 图中的 PDF 内页只作预览示意；本轮不调整后端 PDF 内页模板。
- 不从页面效果图或旧设计系统总览裁切运行时素材；本次用户专门提供的透明素材总览可以作为五项素材的裁切源。
- 不因效果图出现而新增语音、收藏、复杂模板商城或其他未定义能力。

## 3. 推荐交互结构

### 3.1 主配置页

主页面按以下顺序组织：

1. 类型选择：练字帖、听写卷、生字卡片，以带图标、名称和一句说明的三列卡片呈现。
2. 内容选择：显示当前教材、已选课文、字数；点击进入教材与课文弹层。
3. 手动内容：保留手动输入生字；标题和拼音修正折叠到“手动添加 / 内容设置”。
4. 效果预览：有内容时展示真实首行或首屏预览；无内容时展示明确空状态。
5. 样式摘要：以一行摘要显示当前字体、格线、纸张、拼音和描红遍数。
6. 主操作：“生成字帖 / 生成听写卷 / 生成生字卡片”。
7. 次操作：“更多设置”，进入样式设置页或设置弹层。

主操作不应写成“下一步：更多设置”。使用默认值的用户无需强制经过设置页。

### 3.2 教材与课文弹层

复用现有弹层的数据读取、古诗词单选、旧版教材提示和导入逻辑，将课文选择由多选改为单选，并调整布局与状态表达：

- 顶部保留“课文生字 / 古诗词”页签。
- 教材、年级、学期和内容分类根据现有真实数据展示，不写死效果图中的数量。
- 课文列表显示选中状态和单课字数；同一时间最多存在一个选中项。
- 点击另一课时直接替换原选择；再次点击当前课可取消选择。
- 删除“全选本组”和“可多选”等入口与文案，底栏显示当前课名、字数和模式上限。
- 练字帖、听写卷上限为 30 字；生字卡片上限为 20 字。当前教材数据共 321 条课文，单课最多 16 个生字，均未超过现有限制。
- 保留加载、加载失败、无数据、超限、取消和重新选择状态。

单课限制属于当前小程序的产品交互约束。现有创建接口只接收最终汉字和标题，不识别教材课文身份，因此本轮不把该限制描述为不可绕过的服务端广告/付费边界。未来接入广告解锁时，应同时设计服务端权益校验和课文来源标识，不能只依赖前端选中状态。

### 3.3 更多设置

本轮只映射现有参数：

| 设置项 | 当前值域 | 改版处理 |
| --- | --- | --- |
| 字体 | 正楷、行楷 | 图形卡片选择，练字帖和生字卡片显示 |
| 格线 | 田字格、米字格、方格 | 三列卡片选择 |
| 纸张 | 仿真字帖纸、素雅 | 双列卡片选择 |
| 显示拼音 | 开/关 | 使用微信原生开关；听写卷按现有规则固定开启 |
| 描红遍数 | 0–8 | 暂保留现有值域，采用离散选择或带刻度控件；是否缩减为 1–4 需另行确认 |

设置变化后预览应同步刷新。返回主配置页时保留用户已选内容和设置。

### 3.4 生成结果页

复用现有生成详情和 PDF 打开能力，视觉上与新版对齐：

- 顶部显示标题、类型、字数和页数。
- 中间显示真实字帖预览，并保留滚动或放大查看能力。
- 主按钮为“打开 PDF”。
- 次按钮为“打印链接”和“重新编辑”。
- 保留 10 天记录期限说明、加载状态、过期状态和 PDF 下载失败提示。
- 当前“重新编辑”会删除已生成字帖，改版时必须在确认弹窗中继续明确，不把它表现成无损返回。

## 4. 数据与状态设计

本轮优先保留 `pages/chinese/chinese.js` 的现有字段与请求结构，UI 拆分不改变创建字帖接口：

- `modeIndex`
- `chars`、`title`、`pinyinOverride`
- `paperIndex`、`gridIndex`、`fontIndex`
- `showPinyin`、`traceCount`
- 教材、课文、古诗词和选择统计
- `quotaRemaining`、`submitting`

如拆成独立设置页，需要通过页面事件、临时页面状态或明确的参数对象传递设置；不使用不受控的全局变量。用户返回、取消或生成失败时，已输入内容不得丢失。

课文选择状态由多值 `selectedSet` 收敛为单值课文索引或课文 ID；不保留无效的批量选择状态。手动输入仍是独立内容来源，不伪装成已选课程。

即时预览优先复用现有 `sheet-view` 的视觉语义或抽取一个轻量预览组件。预览只表现实际能够生成的内容，不使用与最终 PDF 不一致的静态示意图。

## 6. 建议实施顺序

1. 固化页面状态映射和视觉令牌，确认设置页采用独立页面还是弹层。
2. 重组主配置页，但先保持所有现有事件和提交参数不变。
3. 调整教材弹层，将课文多选改为单选，移除批量选择，并修正字数上限显示与提交规则不一致的问题。
4. 接入真实即时预览和样式摘要。
5. 实现可选的更多设置，并验证返回后的状态保留。
6. 调整结果页视觉和准确文案。
7. 将服务端默认日配额调整为 3，同步关于页、README、错误提示与测试；检查部署环境是否显式设置旧值 8。
8. 补齐加载、空状态、失败、超限、配额为零及重复提交状态。
9. 完成开发者工具与真机回归，再提交用户验收。

## 7. 验收标准

### 功能回归

- 三种类型都能创建，提交参数与改版前一致。
- 手动输入、标题、拼音修正、单课导入和古诗导入可用。
- 课文列表任意时刻最多选中一课；切换课文会替换原选择；不存在批量全选入口。
- 字数限制随模式正确变化，计数、按钮禁用和错误提示一致。
- 听写卷继续固定显示拼音，并隐藏不适用的字体、格线和描红设置。
- 修改设置后预览、生成结果和 PDF 参数一致。
- 生成失败不丢内容；重复点击不会重复提交。
- 结果页可打开 PDF、复制打印链接和重新编辑。
- 未显式配置 `DAILY_SHEET_LIMIT` 时，普通登录用户或带客户端 ID 的用户每日第 1–3 份成功，第 4 份返回 `DAILY_LIMIT`；配额查询同步返回 3 份总额及正确剩余数。
- 语文、数学、英语创建继续共享同一每日配额；VIP、白名单用户和 IP 兜底策略不因本次调整发生变化。

### 视觉与交互

- 主蓝用于主操作，语文红用于学科与选中状态，橙色不作为语文页主色。
- 页面与首页的圆角、阴影、间距、文字颜色和图标风格一致。
- 选中状态不只依赖颜色，同时有边框、勾选或其他可见标记。
- 常用流程无需进入更多设置即可生成。
- 主要点击区域不小于约 44×44 CSS px；小文字操作扩大整行热区。
- 小字号说明文字在真机上清晰，浅灰与浅红文字通过对比度检查。
- 刘海屏、安全区、较小屏幕和系统大字体下无按钮遮挡与内容截断。

### 测试范围

- 微信开发者工具：iPhone 常见尺寸、Android 常见尺寸。
- 至少一台 iOS 和一台 Android 真机验证滚动、输入、弹层和 PDF 打开。
- 回归现有后端 API 测试与 layout 测试；本轮不以截图替代功能测试。

## 8. 风险与回退

- 拆页后最主要风险是内容和设置状态丢失；实现时先建立单一配置对象并覆盖返回场景。
- 即时预览若直接复用完整排版组件可能影响性能；先以首行轻量预览验证，避免在输入时生成完整 PDF。
- 低分辨率小墨素材放大后会发虚；正式实现不强行放大现有 65–80px 裁切图。
- 改版与 PDF 模板解耦，出现问题时可回退前端页面，不影响后端生成记录。
- 若生产部署显式配置了 `DAILY_SHEET_LIMIT=8`，只改代码默认值不会生效；发布时必须核对并调整部署环境，且不得误改 `IP_DAILY_SHEET_LIMIT=50`。
- 单课选择仅是未来广告流程的前端基础，不等于广告防绕过机制；接广告前仍需补服务端权益与来源校验。

## 9. 开工确认项

开始修改业务代码前需由用户确认：

1. 采用“直接生成 + 更多设置”的双入口，不强制经过设置页。
2. 描红遍数本轮继续支持 0–8，还是改为新版图中的 1–4。
3. “更多设置”使用独立页面还是底部弹层；建议独立页面，空间更稳定。
4. 本轮不新增“生字详解”“强化练习”和真正的“发送到电脑”能力。
5. 已收到 2026-09-14 素材总览；实施时从用户提供的透明 PNG 中提取三个模式图标和两张小墨，不从旧设计总览二次裁切。

- 语文教材课文：一次只能选择一课，选择新课替换旧课。
- 本轮只为未来广告流程建立单课节点，不接入广告 SDK、广告位、观看状态或奖励次数。

## 11. 实施记录（2026-09-14）

- 已创建并使用分支 `codex/chinese-copybook-ui-refresh`。

## 12. 分享奖励追加规则（2026-09-14）

- 基础日配额仍为 3 份，分享奖励作为当天额外额度叠加，不修改 VIP、分钟限流和 IP 兜底规则。
- 分享给好友后，好友实际打开分享链接，发起人增加 1 份；同一好友当天只奖励一次。
- 分享到微信群后，群成员实际从群内打开，服务端解密并校验 `shareTicket` 中的 `openGId`，发起人增加 5 份；同一群当天只奖励一次。
- 微信页面分享配置不提供可信的“发送成功”回调，因此奖励以链接被打开为到账条件；自己打开自己的链接不奖励。
- 分享意图 24 小时有效并只能结算一次；伪造群证明、无会话请求和重复结算均由服务端拒绝或按 0 奖励幂等返回。
