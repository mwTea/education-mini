# 数学出题规则（题卡与在线练习）

> 唯一规则入口：想看出题逻辑，读本文档即可；代码只是实现。
> 代码位置：`backend/src/services/layout/math.service.js`（生成器主体）、
> `math-curriculum.js`（册别口径/单位池/知识点判定）。改动规则时**同步更新本文档**。
>
> 最后复核：2026-09-11（几何题型补充 + 应用题重写）。

## 1. 总体模型：册别 × 难度 双轴

- **册别（book）定"学什么"**：每册映射若干题型（计算单元），依据教材目录：
  人教/冀教均按电子课本网 2026-09 采集的目录整理；冀教几何单元（三上第六单元周长、
  三下第七单元面积、五上第六单元多边形面积、六上第四单元圆）与人教对应册别一致。
- **难度（difficulty）在同一单元内分档**：`basic 基础 / standard 巩固 / advanced 培优`。
  总原则：**基础=小数值、单步骤；巩固=单元典型口径；培优=大数值、两步/逆向题**。
  难度不改变知识点（不越册别）。
- 产出 layout JSON：`{ pages:[{rows}], answerPage, questions }`，
  row 分 `inline 口算 / vertical 竖式 / word 应用题 / clock 钟表 / section 大题标题`。

## 3. 计算题型规则（口算/竖式）

通用防呆：不出 0/负数结果；避免 `a+0`、`a×1` 类低价值题；进退位、数位宽度由难度控制。

| 家族 | 题型（ID） | 规则要点 |
| --- | --- | --- |
| 加减法 | add-10 / sub-10 / add-20 / sub-20 / add-100 / sub-100 / add-10000 / sub-10000 | 范围随册别；basic 不进/不退位，standard 混合，advanced 恒进/退位；万以内 basic 封顶 999 |
| 填空/连算 | bracket-add / bracket-sub / chain-add / chain-sub / compare | 括号求 Missing addend；连加连减控制每步不超过口径；比大小 advanced 到 100 |
| 表内乘除 | mul-table / mul-inverse / div-table / div-remainder | 2~9 口诀空间；乘法填空求因数；有余数除法余数 < 除数 |
| 乘除一位数 | mul-1digit / div-1digit / vertical-mul / vertical-div | 口算与竖式共用范围：乘 advanced 至 2999，除 advanced 商至 999 |
| 两位数乘除 | mul-2digit / div-2digit | 口算/笔算：乘 11~99，除数两位数时除数 11~49 |
| 混合运算 | mixed-2step / mixed-paren | 两步、含括号；先乘除后加减 |
| 小数 | decimal-add / sub / mul / div / vertical-decimal | 一位小数为主；乘除结果两位小数；竖式版式 |
| 分数 | fraction-add / fraction-add2 / fraction-mul / fraction-div | 同分母加减；结果**必约分**（§6 分数规则）；乘除结果最简 |
| 百分数/比例 | percent / ratio-fill | 百分数取 10/20/25/50/75/80 与整十基数，保证整数结果；比例填空用比例基本性质 |
| 钟表 | clock-read / clock-draw / time-elapsed | basic 半点、standard 5 分倍数、advanced 任意分；画钟面出 SVG |

**几何计算**（2026-09 新增，答案为纯数字，单位写在题面）：

| 题型（ID） | 册别 | 规则 |
| --- | --- | --- |
| perimeter 长方形正方形周长 | 三上（两版） | 长方形约 2/3、正方形约 1/3；长 basic 3~9 / 巩固 5~15 / 培优 8~20，宽小于长；周长 = 2×(长+宽) 或 4×边长 |
| area 长方形正方形面积 | 三下（两版） | 宽/边长 ≤9、长 ≤15，保证乘法不超"两位数×一位数"口径 |
| polygon-area 多边形面积 | 五上（两版） | 平行四边形/三角形/梯形等概率；三角形、梯形高取偶数保证整除；底培优至 25 |
| circle 圆的周长和面积 | 六上（两版） | π=3.14；周长/面积各半；巩固起随机出"知周长求直径"；结果保留两位、去尾零 |

## 4. 单位换算（unit-convert）

- **单位池按册别**（`SCOPES`），只出已学单位；每题随机大→小（乘进率）或小→大（除进率，约 55/45）。
  面积单位（平方米/平方分米/平方厘米）随三下面积单元进入；体积/容积在五下。
- **数量分档与单位无关、只看难度**（2026-09 修正：此前用"运算口径÷进率"压缩，
  导致进率 1000 的单位恒为 1、题面全是 1 或 10 的倍数）：
  - 基础 2~9；巩固 2~20；培优 11~上限（时间类 24；一二年级 20；三四年级 49；五六年级 99）。
- 时间单位（时/分、分/秒）数量有自然上限，不再放大。

## 5. 应用题（word-problem）规则

### 5.1 知识点判定

知识点由**本册题型自动推导**（`wordTopics()`），应用题不会出现本册没学过的知识：

| 知识点 | 触发题型 | 场景模板数 |
| --- | --- | --- |
| additive 加减应用 | 任一 add-/sub-/chain- | 小数量 6 + 大数量 5 + 逆向 2 |
| multiply / divide 乘除应用 | 任一 mul-/div-/vertical- | 4 / 3 + 表内变体 |
| decimal 小数应用 | 任一 decimal | 按子能力 2~4 |
| fraction 分数加减应用 | fraction-add（初步）/ fraction-add2 | 3 / 2 |
| fraction-mul / fraction-div | 对应题型 | 2 / 3 |
| percent / ratio / volume | 对应题型 | 3 / 2 / 3 |
| perimeter 周长应用 | perimeter（三上） | 4（长/正方形） |
| area 面积应用 | area 或 polygon-area | 4 / 4（按五上区分多边形） |

### 5.2 数值范围跟教材走（核心规则）

- **加减**：按本册口径选数量级——20 内 / 100 内 / 万以内；万以内换大数量语境
  （图书馆藏书、体育场座位），不再出现"图书角几千本书"。
- **乘除**：按本册能力三档——表内（每份、份数均 2~9）→ 多位数乘除一位数
  （份数 2~9）→ 两位数（每份、份数均两位数）。复习表内除法的册（如人教五下）
  只出表内题，不越级。
- **分数**：见 §6。
- 每个知识点 2~4 个场景模板，同卷题干去重，避免"同句式换数字"的重复感。

### 5.3 难度在应用题中的体现

- 数值分档：基础取低段、巩固取中段、培优取高段（各知识点显式定义）。
- 培优专项题型（仅 advanced 出现，约 1/3~1/2 概率）：
  加法**逆向求原数**（"开走 a 辆还剩 b 辆，原来有多少"）、表内**乘加两步**、
  **包含除**（求份数）、按比例分配**求部分量**、分数乘法**求剩余**（两步）。
- 基础档只出单步直进题。

## 6. 分数与约分

- 所有分数结果（口算与应用题）**必须最简**：约分复用 `fraction()`，不出现 `5/5`、`11/11`。
- 三上"分数初步"（只有 fraction-add）：分母 3~9、两部分之和小于整体、
  且天然最简（该阶段未学约分，答案保持未约分形态但数值上已最简）。
- 五下起"同分母加减"（fraction-add2）：分母 4~12、和可等于整体（答案化简为 1）、
  培优混入"比多少"（减法）。
- 分数乘除应用：总量为分母倍数保证整数；除法结果最简分数。

## 7. 去重与题量

- 同卷按**完整题干字符串**去重（钟表含指针参数）；每题最多尝试 300 次。
- 找不到新题时自动**换同册相邻题型**补位；整卷无题可换才允许重复，并在卷面提示
  "所选题型的不同题目有限，已在所选范围内安排重复巩固"。
- 上限：整卷 ≤100 题；纯应用题卷 ≤10 题（`MAX_WORDS`）。

## 8. 排版与编号

- 分区顺序：口算题 → 单位换算 → 竖式计算 → 应用题 → 认识钟表 → 画钟表；大题标题带序号（"1、口算题"）。
- **题目区小题不带序号**（2026-09 按需求调整：序号与题目数字混淆），题目按大题内
  从左到右、逐行阅读顺序排列；**答案页保留"题号. 答案"**，便于逐题核对。
- 版式：口算按题干宽度 2~4 列；竖式 2 列留笔算空白；应用题单列带书写横线；
  钟表 4 列 SVG；A4 每页内容高 ≤240mm 自动分页（大题跨页带"（续）"）。

## 9. 在线练习（POST /api/v1/math/quiz）出题规则

- 复用同一生成器，按册别难度出整卷口算，不落库、不占生成配额。
- **排除**竖式、应用题、钟表、比大小、分数、有余数等在线输入体验差的题型
  （`QUIZ_TYPES` + `fraction-*` 过滤）；几何计算（周长/面积/圆）为纯数字答案，
  已纳入在线练习（答题键盘含小数点，按数值判分）。

## 10. 有意未收录（非缺陷）

公顷/平方千米（大数换算）、圆环面积、圆柱圆锥、负数计算、角度、统计图表——
属打印深水区或在线体验差，待有真实需求再评估。打印 PDF 内页模板另见产品原则。

## 11. 维护指引

新增/调整题型五步：

1. `math.service.js` 的 `TYPES` 加生成器（难度参数 `d`，范围显式分档）；
2. `TYPE_LABELS` 加名称（出题页题型选择用）；
3. `PEP_BOOKS` / `JJ_BOOKS` 对应册加题型 ID（**先核对教材目录**，注明来源）；
4. 若可作应用题：`math-curriculum.js` 的 `wordTopics` 加触发规则、
   `curriculumWord()` 加场景分支、`WORD_LABELS` 加名称；
5. `test/math.test.js` 补断言（册别收录 + 答案与公式一致），跑
   `node --test test/*.test.js`，并同步更新本文档。
