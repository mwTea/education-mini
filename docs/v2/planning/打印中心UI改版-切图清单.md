# 打印中心 UI 改版切图清单

日期：2026-09-14

适用方案：方案 A（不展示最近打印，已实施）

视觉参考：[打印中心 UI 方案 A/B](../ui/source/打印中心UI方案AB-2026-09-14.png)

## 1. 必须提供的切图

请优先提供以下 **6 张独立透明 PNG**。不要从当前 1024×1536 的整页效果图直接裁切；效果图已经合成背景、文字和阴影，直接裁切会带来白边、文字粘连和分辨率不足。

| 建议文件名 | 内容 | 推荐源尺寸 | 运行时用途 |
| --- | --- | ---: | --- |
| `print-hero-xiaomo.png` | 小墨抱练习册 + 打印机 + 出纸 + 与主体相连的绿色装饰；不含文字、勾选项、蓝色背景 | 不小于 1200×700 px | 顶部 Hero 主插画 |
| `print-footer-xiaomo.png` | 小墨抱铅笔 + 书本；可保留贴近角色的星星，不含手写文案、蓝色背景 | 不小于 1000×600 px | 方案 A 页尾品牌卡 |
| `tool-radicals.png` | 偏旁部首图标，交叉笔画/铅笔语义 | 256×256 px | 专项工具图标 |
| `tool-name-sheet.png` | 名字字帖图标，姓名贴/字卡语义 | 256×256 px | 专项工具图标 |
| `tool-test-paper.png` | 测试小卷图标，试卷语义 | 256×256 px | 专项工具图标 |
| `tool-print-history.png` | 打印历史图标，时钟/历史语义 | 256×256 px | 专项工具图标 |

如果设计侧能提供 SVG 原稿，也请一并保留作为源文件；小程序运行时仍建议导出 PNG，避免 SVG 兼容和远程资源限制。

## 2. 导出要求

- PNG 使用透明背景、sRGB 色彩空间；每张只包含对应主体。
- 四周至少保留约 6%–10% 透明安全区，不要贴边裁切耳朵、纸张、星星或阴影。
- 阴影可以保留在主体内部，但不要带整块白底或 Hero 的蓝色渐变底。
- 不要包含“打印中心”“打印学习，从这里开始”“好资料，让学习更轻松”等文字。
- 不要包含状态栏、微信胶囊、导航栏、TabBar、右箭头或卡片背景。
- 不要把多张素材放在一张总览图里；每个文件应能直接用于 `<image>`。
- 主插画建议同时交付无损 PNG 源文件；不要只给经聊天工具压缩后的 JPG/截图。
- 文件名使用英文小写和连字符，避免后续构建工具或 CDN 对中文路径处理不一致。

## 3. 不需要切图的内容

以下内容由 WXML/WXSS 或项目现有资源实现，无需另出图片：

- Hero 与页尾卡片的浅蓝渐变背景、绿色装饰底块。
- 标题、副标题、勾选项、手写氛围文案。
- 三科学科卡片的渐变/浅色背景和“语 / 数 / ABC”文字图标。
- 区块标题、辅助说明、右箭头、更多菜单点和“后续开放”标签。
- 微信系统栏、导航栏、胶囊按钮和底部 TabBar。
- 最近打印缩略图；方案 A 不展示最近打印。
- PDF 内页预览和纸张背景；本轮不修改 PDF 模板。

## 4. 可接受的精简交付

如果暂时只能提供两张图，先交付：

1. `print-hero-xiaomo.png`
2. `print-footer-xiaomo.png`

四个专项工具图标可以先用 CSS 形状、文字或仓库现有小图标做临时实现，但视觉还原度会低于效果图；正式验收前仍建议补齐四张独立图标。

仓库现有 `miniprogram/assets/mascot/` 小墨单图只有约 65–80px，`miniprogram/assets/quick/` 图标为 96×96px，且构图与本次效果图不同；它们可作临时占位，不适合放大后作为本次 Hero 或正式专项工具素材。

## 5. 收到素材后的验收项

- 检查真实像素、透明通道、有效内容边界和文件体积。
- 在浅蓝、白色两种背景上检查白边、黑边和半透明污染。
- 按小程序实际展示尺寸检查 2×/3× 屏清晰度。
- 确认插画是原版小墨，不混入另一套已放弃的角色设计。
- 确认素材没有烘焙产品文案，便于后续改字和国际化。
