## 三、P2 路线图（1.0 之后）

### 账号体系 + 个人中心 + 管理后台 + 会员（已立项设计，下轮实施）

**A. openid 登录（无感）**
- 前端 app.js 启动 wx.login → code 发后端 `POST /api/v1/session`（AppSecret 存服务器环境变量，code2Session 换 openid，绝不下发前端）
- 后端 users.json 存 {openid, createdAt, lastSeenAt, vip: false, vipUntil?}；会话用内存 token 或直接每次带 code（简化：前端缓存 3rd session 意义不大，直接 openid哈希做 X-User-Key？——规范做法 code2Session + 后端发随机 token 存 users）
- 请求头 X-Client-ID 升级为 X-User-Token（保留旧头兼容）

**B. 配额改为按 openid（ vip 豁免）**
- quota.middleware：token→openid→查 users：vip=true 且未过期 → 跳过每日配额（分钟限流保留）；否则按 openid 计 3 份/天，IP 兜底 50/天 保留
- 开通会员入口（个人中心）：先做 UI 占位 +「敬请期待」，支付后接

**C. 管理后台（手机 H5，后端直接 serve，无独立工程）**
- `/admin` 返回单文件移动版 H5（后端 express 路由内联 HTML，无构建、无依赖）：手机浏览器/微信里打开
  · 打开时 URL 带 `?token=ADMIN_TOKEN`（env 配置）或页内输入 token，localStorage 记住
  · 看板卡片：累计用户 / 今日活跃 / 今日生成量 / 7 日趋势（迷你条形图 CSS 实现）/ 字帖类型分布
  · 会员管理：粘贴 openid → 开通 N 天会员 / 查询用户状态（即"后门"的操作界面）
- 数据接口：`GET /api/v1/admin/stats`、`POST /api/v1/admin/vip`（均 Token 鉴权）
- 另加白名单后门：服务器 `data/vip-openids.txt` 一行一个 openid，quota 中间件读取即免限，不动代码

**D. 个人中心（新 tabBar 第三项「我的」）**
- 头像昵称（可选授权，不强制）/ 今日剩余配额与会员状态
- 我的生成（历史复用）/ 常用工具（偏旁部首/口算快捷）
- 开通会员（占位）/ 意见反馈 / 关于与隐私

**E. 实施顺序**：session 接口+users 存储 → quota 接 openid+vip/vip-openids 双通道 → admin stats/vip 接口+静态板 → 前端登录+个人中心页 → 测试部署



### 数学口算题卡（已立项 · 优化设计蓝图，非纯移植）

参考：`杂项工作区/ideas/mathprint-kids`（Taro 半成品，生成器可参考，版式作废重做）。

**A. 出题规则优化**（原版生成器的缺陷 + 本版设计）：
1. 进位/退位控制：原版 100 内加减不区分进退位（一年级下只学不进位）——本版按册别自动控制，可选"强制进位/退位"专项
2. 新增一年级高频题型：括号题 `( )+4=9`、连加连减 `3+5+2`、比大小 `6○8`（原版只有小数比大小）
3. 表内乘除含逆运算 `□×6=42`；三年级除法带余数按"被除数=除数×商+余数"生成（原版做法保留）
4. 防呆规则：不出结果 0/负数；避免 a×1、a÷1、a+0（可开关"基础题"）；同卷相邻题不同型；表内乘法空间不足 64 题时自动提示降题量或混入相邻题型（原版会静默放弃去重）
5. 应用题模板库扩充到 ≥12 个场景（买东西/分东西/路程/植树/年龄差），参数与答案整数化校验
6. 难度双轴：年级学期定"学什么"（教材单元），难度档定"练多深"——基础（本单元最小要求，如 100 内不进位）/ 巩固（常规练习，含进退位）/ 培优（数字上限放大、混合邻近单元、括号题变式）；难度在同一单元内调制参数，不跨纲

**B. 年级课程选择**（对齐人教版数学，同语文英语的"课程感"）：
- 按册别聚焦核心计算单元：一上10内加减/连加连减/括号题；一下20内退位减/100内不进位/人民币换算；
  二上表内乘法/100内进退位；二下表内除法/带括号两步混合；三上万以内加减/多位数×一位数/时分秒/同分母分数；
  三下除数一位数/两位数×两位数/小数初步；四上三位数×两位数/除数两位数；四下运算定律/小数加减；
  五上小数乘除/简易方程；五下分数加减；六上分数乘除/百分数
- 选择流：年级学期 → 难度（基础/巩固/培优）→ 题型自动推荐并允许多选微调（沿用语文教材弹框交互）
- 数据标注"以实际课本为准"（同语文旧版课目教训）

**C. 页面与渲染**（适配本小程序设计语言，多页流不挤一页，预留广告位）：
- 拆两页而非一页：
  · pages/math/index 出题主页：年级学期选择 + 难度（基础/巩固/培优）+ 常用模板快捷卡（"每日50题"等）——页面底部预留 banner 广告位容器
  · pages/math/config 配置页：题型自动推荐+多选 / 题量(20/50/100) / 进退位专项开关 / 答案页开关 → 生成
- 广告位规划（仅预留容器，不接代码）：出题主页底部 banner；配置页生成成功后的插屏（激励视频可对"再生成一次"场景）；页面拆分本身就是为了这些位子自然存在、后期接入零改版
- 预览与 PDF：走现有矢量管线与 preview 页体系；口算 A4 竖版 3 列、列间淡虚线分隔（口算卷经典版式）、题号灰字右对齐；
  竖式题画计算框（两数上下+横线）不跨页；应用题题干自动换行+答题留白；答案页独立成页 4 列紧凑
- 信息栏适配数学场景：姓名___ 日期___ 用时___ 得分___（替换语文的姓名/班级）
- 计入每日 3 份配额；题量上限 100、应用题上限 10；PDF 中 ×÷=○ 等符号先验证 UKai 字形覆盖，缺则用全角替代

**D. 实施顺序**：math.service.js（生成器+册别/难度双轴+测试）→ pdf/html 渲染 → sheets 接口 → 前端出题主页+配置页+sheet-view 数学行渲染 → 首页入口卡片「数 · 口算题卡」

## 四、已知限制（1.0 可接受，客服话术参考）

- 三/五/六年级为旧版课目（导入弹框已标注），以孩子实际课本为准
- 部分英语单词无中文释义，中译英会自动转英译汉（卷面有说明）
- 每台设备每天 3 份；字帖记录服务器保留 10 天，过期重新生成即可
- 历史记录仅保存在本机微信里
- 自动注音多音字偶有误差，可用「拼音修正」输入框覆盖

## 五、关于页 / 隐私政策内容要点（下轮实现时直接抄）

- 不收集任何个人信息：无登录、无定位、无设备信息上报（配额用的设备 ID 为本地随机数，仅用于当日计数）
- 生成内容（生字/单词文本）仅用于排版，记录保留 10 天后自动删除
- 数据来源：古诗词为公版作品；生字表整理自人教版教材写字表；词库整理自 PEP 教材词汇表，中文释义为自录
- 字体版权：AR PL UKai（文鼎楷体，Arphic 公共许可证，随包附 `backend/assets/fonts/UKai-CN-license.txt`）；演示夏行楷（OFL）
- 儿童使用请家长陪同打印；内容如涉及版权请联系下架
