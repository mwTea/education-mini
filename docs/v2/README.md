## 版本与使用边界
- 本次提供的四份文档文件名及正文均为 v1.0。原对话曾提到产品、功能 v1.1，但此次未提供，不将 v1.0 改名冒充 v1.1。
- 功能实现优先级：Sprint 任务书 > 技术详细设计 > 功能详细设计 > 产品迭代设计；发现冲突先结合现有实现审计。
- 路线图按学科拆分 Sprint，与任务书的孩子档案、统一练习引擎、打印等顺序不一致。实施顺序以任务书为准。
- 视觉沿用原版小墨与原有 UI 体系。图中题型、语音、收藏等旧功能不自动纳入首版；全流程优先参考 10_30_56 的无语音版本，10_32_42 含语音入口，仅作旧版参考。
- 10_27_40 与 10_33_28 可参考页面布局、建档与品牌表现，功能范围须按任务书和技术文档核对。
- 打印图中的 PDF 内页是示意，具体模板仍待单独确定。
- 打印中心方案 A/B 效果图仅作为视觉与信息层级参考；图外方案说明、未落地题型与直连打印表述不自动成为功能需求。
- 当前未发现独立小墨透明底切图。角色状态包含在 Design System 及 UI 总览中；ui/mascot/README.md 提供入口，不把整张图当成可直接使用的单个素材。
