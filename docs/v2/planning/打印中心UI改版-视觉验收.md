- 打印页 WXML 已通过微信开发者工具内置 `wcc` 编译器。
- 打印页 WXSS 已通过微信开发者工具内置 `wcsc -lc` 编译器。
- 页面绑定的 `openSubject`、`goRadicals`、`goNameSheet`、`comingSoon`、`goHistory` 均存在，原有跳转逻辑未改。
- 六张打印页运行时素材均为带透明通道的 PNG，单张约 19–113 KB；WebP 版本因 iOS 预览版未显示已移除。
- 首页横幅与三科学科图标完成像素尺寸优化，页面路径与引用不变。
- `node scripts/check-miniprogram-size.js` 通过：改用兼容 PNG 后主包原始文件合计 1410.6 KB / 1500.0 KB；最大媒体文件 128.8 KB / 200.0 KB。
- `print.js`、体积检查脚本和 JSON 配置语法检查通过。
- 修复按钮重置样式覆盖三科学科卡片渐变的问题；语文、数学、英语入口分别恢复浅红、浅蓝、浅绿底色，并再次通过 WXSS 编译。
- 全量文件签名扫描确认 `miniprogram/` 内没有无扩展名或伪装格式的图片/音频；微信开发者工具缓存中发现旧版大图记录，已清理项目编译缓存并重新打开项目编译。
- iOS 预览版实测发现本地 WebP 不显示，表现为 Hero 和专项工具只剩背景色块；现已改为透明 PNG、删除 WebP 文件并再次清理编译缓存。

## 视觉核对重点

- Hero 文字与右侧小墨不互相遮挡，插画透明边缘在浅蓝背景上无明显黑边。
- 三科学科卡片保持语文红、数学蓝、英语绿，与首页和语文字帖改版一致。
- 测试小卷同时显示“后续开放”，不让用户误认为功能已上线。
- 两列专项工具在小屏下不截断；极小屏隐藏“后续开放”小标签，但保留无障碍说明和点击提示。
- 页尾小墨不覆盖文字，不与底部 TabBar 或安全区冲突。
