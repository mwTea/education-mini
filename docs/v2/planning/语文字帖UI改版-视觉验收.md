## 对照结果

| 优先级 | 发现 | 修正与复测 |
| --- | --- | --- |
| P1 | 生字卡片模式仍复用描红行预览，无法表达卡片内容 | 改为卡片专属预览，展示真实拼音、笔画、部首、结构、组词及练习格；“潮”复测为 15 画、氵部、左右结构 |
| P1 | 手动输入展开后，原生 `textarea` 自动高度导致说明和拼音输入框叠压 | 取消自动高度，固定文本域与输入框盒模型并增加字段间距；展开态复测无重叠或截断 |
| P2 | 小墨大图直接贴在页面底部，边缘突兀且容易被视口裁切 | 改为蓝白渐变鼓励卡片，小墨从卡片左下自然探出，文字与装饰层形成完整页尾模块 |
| P2 | 旧本地后端仍返回 8 份配额，页面出现“剩余 6 份 / 每天 3 份”的矛盾 | 重启到当前后端代码后，模拟器配额恢复为每日 3 份 |
| P2 | 教材弹层必须清楚表达单选约束 | 增加“选择课文（单选）”、替换说明和禁用态确认按钮，移除批量全选 |
