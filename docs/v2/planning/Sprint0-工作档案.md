- 底部导航调整为：首页、学习、打印、成长、我的。

- 学习页承接现有语文、数学、英语入口；当前可在线练习的数学口算直接复用。
- 打印页承接现有三科生成、偏旁部首和打印历史。
- 成长页只读取设备内已有口算汇总；未实现的语文、英语统计和日历明确标记待开放。
- 我的页面保留当前本地年级、配额、历史、帮助和反馈入口。
- 多孩子切换暂缓；数据库、接口、出题算法和 PDF 内页不在本 Sprint 修改。

## 设计决策

- 现有三科学科配置页继续同时包含在线与打印能力；Sprint 0 只从新的学习/打印入口路由过去，不复制业务页面。
- 成长页展示的数据来源和范围写明为设备内口算记录，避免把占位内容表达成真实服务端统计。
- 专项训练、测试小卷等入口保留视觉位置，点击仅提示后续开放。
- 原版小墨没有独立透明切图前不混用替代角色，也不从总览图直接裁切低质量素材。
