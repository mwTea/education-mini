## 已裁切的状态素材（2026-09-11，用户授权试用）

经用户确认（方案 b），从 Design System 总览图第 08 区裁切 8 个单状态透明 PNG，存放于
`miniprogram/assets/mascot/`：`wave`（打招呼）、`write`（书写）、`cheer`（庆祝）、`encourage`（鼓励）、
`sleep`（休息）、`star`（获星）、`read`（阅读）、`think`（思考）。

边界说明：

- 源图为 1536×1024 总览，单状态原尺寸约 65–80px 见方，已做背景透明（泛洪去底 + 边缘柔化）。
  适合中小尺寸展示；大尺寸使用会偏软。首页 Hero、成长空态、我的头像按 150–190rpx 使用。
- 上方圆色底、投影与状态文字标签未包含在裁切内，仅吉祥物本体。
- 官方独立切图到位后，按同名文件直接替换 `miniprogram/assets/mascot/*.png` 即可，无需改代码。
- 依据 Sprint 0 决策，未从整图里裁切低质量的其他素材；本批裁切是用户明确授权的试用。
