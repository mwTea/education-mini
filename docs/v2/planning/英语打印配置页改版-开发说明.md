# 英语打印配置页改版开发说明

日期：2026-09-14

状态：第一期业务逻辑、透明素材与英文字体选择已实现。

实施记录（2026-09-14）：已按用户确认的“先实现逻辑、后替换透明图”顺序完成教材数据归一化、教材/单元单选、单词/句子/连词成句配置、生成前预览、HTML/PDF/小程序预览渲染，以及字母书写和主题词包入口整理。当前英语 Hero 与题型图标使用页面占位元素，不使用后续提供的白底 JPG；透明切图到位后仅替换资源层。

修订记录（2026-09-15）：移除页面内容区的返回行，改为由真实页面栈驱动微信原生返回；“单词抄写”改名为“单词描红”；删除“更多功能”里与单词练习重复的“单词默写”；根据用户提供的成熟参考重做单词描红、听写单词和听写句子三套 PDF 模板，并从教材练习入口移除英译汉听写。

字体记录（2026-09-15）：英语练习默认使用“衡水体”，同时提供“标准印刷体”和“圆润体”。小程序生成前预览、生成后预览、浏览器打印页与服务端 PDF 均读取同一个 `englishFont` 选项；打印按钮会等待网页字体加载完成后再唤起打印，避免首次打开时因字体尚未就绪而回退。

模板校准（2026-09-15）：单词描红采用固定的“每词一行”模板，因此该模式不再显示无效的描红次数和书写行数；所有单词使用同一字号和字重，长单词通过减少横向重复数量适配。听写单词与听写句子也采用固定模板，配置页不再显示“每题书写行数”，每道题固定只保留一组完整四线三格。

## 1. 背景与目标

现有英语打印页是一张长表单，已支持字母字帖、单词字帖、默写帖、教材词库、主题词包、大小写、纸张和练习次数。新提供的英语数据包将教材内容扩展为带中文释义的单词和带翻译、难度的句子，因此本次不只做视觉换肤，而是重新组织“选教材—选单元—选练习—预览生成”的完整流程。

第一期目标：

- 沿用已实施的语文打印页信息层级，保持主蓝色、英语绿、白色轻卡片和原版小墨体系。
- 将高频选项留在主配置页，大小写、纸张和次数等进入独立“更多设置”页。
- 教材内容一次只选一个单元，选择新单元时替换原选择。
- 第一期落地单词练习、句子练习和连词成句三类核心打印内容。
- 生成前展示当前内容的轻量真实预览，生成后继续复用现有预览、PDF、历史和分享链路。
- 优先复用现有数据、接口、排版和页面状态，不重写稳定功能。

## 2. 已确认的第一期范围

### 2.1 英语打印首页

首页展示四个入口：

1. 单词练习。
2. 句子练习。
3. 连词成句。
4. 更多功能。

页面同时显示当前教材摘要和打印历史入口。“更多功能”第一期只收纳字母书写和主题词包；单词练习已经覆盖两种默写方向，不再重复展示“单词默写”。不展示尚未实现的词义匹配和单词分类。

### 2.2 教材与单元选择

- 第一期仅展示有真实数据的人教 PEP 和冀教版，不展示空的“外研版”入口。
- 选择顺序为教材版本、年级、上下册、单元。
- 单元为单选，列表显示真实单词数和句子数。
- 再次打开选择页时保留当前教材和单元。
- `coverage: core` 的册别显示“核心内容”说明；`core_review_needed` 默认不对普通用户展示，完成教材复核后再开放。
- 系统只显示数据包真实统计，不写死效果图中的单词、句子数量。

### 2.3 单词练习

第一期保留两种练习方式：

| 练习方式 | 题面内容 | 作答区 |
| --- | --- | --- |
| 单词描红（默认） | 英文范词，可选中文释义 | 四线三格内横向重复范字，首个黑色、其余红色描红 |
| 听写单词 | 中文释义 | 四列排版，每题默认三组四线三格 |

“显示中文释义”是单词描红的开关，不再单独占用一种练习方式。教材练习不再提供“提示英文、书写中文”的英译汉听写。单词保持数据包原始大小写；全大写和全小写只作为手动内容或字母书写的扩展设置，不默认改写教材内容。

### 2.4 句子练习

第一期保留两种练习方式：

| 练习方式 | 题面内容 | 作答区 |
| --- | --- | --- |
| 句子描红（默认） | 英文范句，可选中文翻译 | 英文描红 + 空白四线三格 |
| 听写句子 | 编号中文句子 | 默认三组整行四线三格，书写完整英文句子 |

没有语音时不增加含义不明确的“英文默写”。教材句子必须保持原始大小写、缩写和标点，不允许一键转换全大写或全小写。

### 2.5 连词成句

- 题目来自当前单元的 `sentences` 数据。
- 生成时动态打乱词块，不在数据库中预存乱序结果。
- 句末标点不参与乱序；`I'm`、`What's`、`isn't` 等缩写保持为完整词块。
- 中文翻译默认关闭，用户可开启。
- 答案页默认开启，答案按原句输出。
- 长句由排版自动换行，不让用户额外理解“一行/两行”设置。
- 打乱后如果与原句顺序相同，服务端至少重新打乱一次；两个有效词块以上的句子尽量避免原序。

### 2.6 更多功能

第一期只收纳：

- 字母书写：复用现有 26 组大小写字母内容。
- 主题词包：复用现有少儿高频词和核心词汇数据。

词义匹配、单词分类、听音默写、发音、收藏和错题本不在第一期范围内。

## 3. 页面流程与状态

推荐流程：

1. 英语打印首页选择练习类型。
2. 教材与单元选择页单选内容。
3. 进入共用配置页，根据练习类型显示对应选项和真实预览。
4. 用户可直接生成，或进入独立“更多设置”页。
5. 生成后进入现有预览/结果页，可打开 PDF、保存或复制打印链接。

返回统一使用微信小程序原生导航栏。首页、教材选择、练习配置、样式设置和更多功能通过真实页面栈衔接，不再在同一页面实例内切换；正常返回顺序为“样式设置 → 练习配置 → 教材选择 → 英语首页”，页面间共享当前流程草稿。

实现时必须覆盖：

- 教材、年级、学期和单元的加载、空、失败和重试状态。
- 更换单元后，当前练习类型和样式设置不丢失。
- 返回、取消、生成失败和配额不足时，已选内容不丢失。
- 有内容时预览真实首词或首句；无内容时显示明确空状态。
- 按钮加载、禁用和重复提交防护。
- 普通用户每日 3 份的共享配额和已实施的分享奖励继续复用。

## 4. 配置页信息架构

共用配置页按以下顺序组织：

1. 当前教材与单元摘要，提供“更换单元”。
2. 练习方式。
3. 与当前方式相关的中文释义/翻译、答案页等开关。
4. 轻量真实预览。
5. 样式摘要和“更多设置”。
6. “预览生成”主按钮。
7. 剩余配额和分享奖励入口。

主页不再平铺全部纸张、大小写和次数控件。独立设置页根据当前练习类型隐藏不适用项，并实时更新预览。

教材选择页在筛选项下显示“当前教材”摘要卡，单元行同时使用勾选、左侧蓝条、浅蓝背景和“已选”标签，避免仅靠单选圆点表达。样式设置页固定展示即时效果卡；即使页面被系统直接恢复、尚未重新拉取教材数据，也使用同类型示例内容展示字体、纸张和行数效果。

## 5. 数据接入与兼容方案

新数据包共 16 册、84 个单元、450 条词汇和 191 条句子。新旧数据结构不同：

- 旧单词：`"apple"`
- 新单词：`{ "word": "apple", "meaning": "苹果" }`
- 旧句子：`"I have a cat."`
- 新句子：`{ "text": "I have a cat.", "translation": "我有一只猫。", "level": 1 }`

后端需要增加统一归一化层，保留对现有主题词包字符串数组的兼容。教材列表返回词数、句数、`coverage`、版本和说明；详情返回完整的单词和句子对象。

不能直接把新 JSON 覆盖到现有目录：

- 前端当前将 `words` 当作字符串，直接覆盖会出现 `[object Object]` 或练习内容为空。
- 新词义应作为当前内容一起传入排版，不再仅依赖独立 `zh-dict.json`。
- 旧 `jj-3a-sentences.json` 与新 `jj-3a.json` 使用相同 ID，接入时必须合并或安全替换，不能并存。
- 数据包中 4–6 年级多数册别是核心内容而非完整词表，页面和接口不得暗示“全量覆盖”。

## 6. 后端与 PDF 变化

第一期优先在现有 `/api/v1/wordbooks` 和 `/api/v1/sheets` 体系内扩展，不新建平行重复接口。

需改造：

- `wordbook.service.js`：数据校验、新旧结构归一化、词/句统计和覆盖状态。
- 创建字帖参数：保留练习类型、教材 ID、单元号及选项，服务端根据可信词库取得完整内容，避免由前端往返复制大段词义和句子。
- `english.service.js`：保留现有字母/单词排版，新增单词描红、四列听写单词、整行听写句子和连词成句行模型。
- HTML/PDF/小程序预览：增加对新行模型、中文翻译和答案页的渲染。

建议限制：

- 单词每份最多 30 条，继续沿用现有上限。
- 句子每份最多 12 条，单句最多 120 个字符。
- 优先通过单元单选使内容自然落在上限内；超限时明确阻止并说明，不静默截断。

## 8. 视觉、交互与无障碍要求

- 主蓝用于主操作，英语绿用于学科标识和选中状态，不把图中多种粉彩色同时当作主色。
- 选中状态同时使用单选标记、边框和背景，不只依赖颜色。
- 整行选项均可点击，主要点击区不小于约 44×44 CSS px。
- 提高效果图中浅灰说明文字的对比度，系统大字体下允许换行，不截断关键教材名和单元名。
- 四线三格、描红和空白行使用真实布局绘制，不用静态预览图替代。
- 加载、失败、无数据、待复核、配额为零和生成中都需有文字说明。
- 常见 iPhone、Android、刘海屏、安全区和小屏滚动不得遮挡主按钮。

## 9. 素材与主包边界

当前小程序主包约为 1410.6 KB，自定义上限为 1500.0 KB，只剩约 89.4 KB。第一期运行时新素材必须尽量控制在 70 KB 以内，为代码和后续修正留出余量。

- 高清源图归档在 `docs/v2/ui/source/`，不进入小程序主包。
- 运行时优先只增加 1 张小墨主插画和 2 张无法用真实文字表达的题型图标。
- `Aa`、省略号、选择圆点、箭头、开关、格线、纸张预览、成功勾和页面背景不做切图。
- 不把真实教材封面整批打入主包；第一期使用统一的轻量教材卡片。
- 任一运行时图片不得超过 200 KB，且提交前必须运行 `node scripts/check-miniprogram-size.js`。

详细要求见[英语打印配置页改版切图清单](<英语打印配置页改版-切图清单.md>)。

## 10. 实施顺序

1. 将英语 JSON 数据包接入内容库；透明源素材允许后补并单独验收。
2. 改造词库归一化层和接口统计，先保证旧主题词包与新教材数据同时可用。
3. 实现英语首页、教材/单元单选和共用配置页，建立稳定的页面状态传递。
4. 扩展单词、句子和连词成句排版，再接入真实即时预览。
5. 实现独立更多设置页和更多功能入口，复用现有字母、默写和主题词包能力。
6. 补齐数据、接口、排版、预览、配额和返回保留状态测试。
7. 在微信开发者工具完成小屏、字体、预览和 PDF 打开回归；上线前补充真机首次加载与缓存回归。

## 11. 验收标准

### 功能验收

- 人教 PEP 和冀教版 3–6 年级上下册按真实数据可选，待复核册别按规则隐藏。
- 任意时刻最多选中一个单元，更换单元会替换旧选择。
- 单词描红和听写单词均能使用数据包真实释义生成，教材入口不再出现英译汉听写。
- 句子描红和听写句子能保留原始大小写、缩写和标点。
- 连词成句乱序、标点、翻译和答案页行为符合本文档。
- 字母书写、主题词包、现有打印历史和 PDF 链路不回归。
- 配置、内容和教材选择在更多设置、更换单元、生成失败和返回时不丢失。
- 无可用内容、数据失败或配额为零时不能重复提交空白字帖。

### 视觉与体积验收

- 与已实施的语文打印页在圆角、间距、阴影、主按钮和设置层级上一致。
- 单词、句子和连词成句都有与最终 PDF 语义一致的生成前预览。
- 默认衡水体及两种备选字体在小程序预览、浏览器打印页与 PDF 中保持同一选择，四线格基线不得因字体切换而漂移。
- 图片失败时不阻塞主流程，页面不出现大片空白。
- 新增运行时素材总量目标不超过 70 KB，单个文件不超过 200 KB，主包保持在 1.5 MB 以内。
- 常见屏幕、安全区和系统大字体下无遮挡、重叠和关键文案截断。
- 主要交互项有语义准确的无障碍标签，选中和禁用状态不只依赖颜色。

## 12. 明确不做

- 不接入外研版或其他未提供的教材数据。
- 不宣传 4–6 年级数据为教材附录全量词表。
- 不新增听音、发音、收藏、错题本、词义匹配或单词分类。
- 不接入广告、付费解锁或真正的电脑/打印机直连。
- 不把效果图整页、状态栏、微信胶囊、文字、卡片背景或 PDF 预览烘焙进切图。
- 不整批将真实教材封面打入小程序主包。
