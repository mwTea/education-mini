# 语文字帖 UI 改版改动说明

日期：2026-09-14
状态：拟议改动，待用户确认后实施。
对应开发说明：[语文字帖UI改版-开发说明.md](<语文字帖UI改版-开发说明.md>)

## 1. 改动摘要

本次计划将语文字帖从“四段长表单”调整为“类型与内容优先、即时预览、设置按需展开”的生成流程，同时把普通用户共享的每日生成上限由 8 份调整为 3 份，并把语文教材课文导入由多选调整为单选。改版不增加新的字帖业务类型，不重做 PDF 排版，本轮不接入广告。

## 2. 页面变化对照

| 区域 | 当前表现 | 拟议改动 | 功能影响 |
| --- | --- | --- | --- |
| 类型 | 顶部三段文字切换 | 三张带图标与说明的类型卡片 | 不改变 `copy/dictation/card` 值 |
| 内容 | 教材导入、手动输入、拼音修正、标题全部展开 | 教材选择突出；手动输入保留；标题与拼音修正适度收起 | 保留全部输入能力 |
| 教材弹层 | 教材四列、分组标签、课文可多选/批量全选 | 按新版视觉重排；课文改为单选，选择新课替换旧课 | 复用现有教材与古诗数据 |
| 样式 | 字体、格线、纸张、拼音、遍数全部在主页面 | 主页面显示摘要和预览，详细参数进入“更多设置” | 默认值可直接生成 |
| 预览 | 生成前只有选项缩略图 | 选择内容后显示真实效果预览 | 新增前端编辑态预览表现，不调用 PDF 生成 |
| 提交 | 长页面底部一个生成按钮 | 主页面固定或就近显示生成主按钮；更多设置为次入口 | 提交接口不变 |
| 结果 | 通用预览页、打开 PDF、打印链接、重新编辑 | 保留能力，调整层级和视觉 | 不增加真正的电脑发送能力 |
| 每日配额 | 普通用户默认 8 份/天 | 普通用户默认 3 份/天 | 三科学科生成共享；VIP 与 IP 兜底不变 |

## 3. 保留不变

- 语文字帖、听写卷、生字卡片三种模式。
- 手动输入最多 30 字；生字卡片最多 20 字。
- 自动注音与手动拼音修正。
- 标题输入与教材导入后的自动标题。
- 单课生字导入、同课生字去重、古诗词导入和标点过滤。
- 正楷/行楷、田字格/米字格/方格、仿真/素雅纸张。
- 显示拼音、描红遍数、每日配额和重复提交保护；每日配额默认值按本次需求改为 3。
- 现有创建字帖 API、历史记录、PDF 下载与 10 天保留说明。

## 4. 明确新增的前端表现

- 类型卡片的图标、标题和说明。
- 已选内容摘要卡片。
- 生成前的真实效果预览。
- 当前样式摘要与“更多设置”入口。
- 教材弹层中与当前模式一致的字数上限状态。
- 教材课文的单选与替换状态，并移除“全选本组”。
- 新版加载、空内容、超限和生成中状态表现。

这些属于现有能力的重新组织，不等同于新增后端功能。

## 5. 明确不做

- 不新增“生字详解”“强化练习”等生成模式或推荐模板逻辑。
- 不新增语音功能。
- 不新增直接发送文件到电脑的服务。
- 不接入广告 SDK、广告位、观看广告状态或奖励次数；本轮只建立单课选择节点。
- 不改变 PDF 内页模板、排版尺寸和后端生成算法。
- 不修改数据库或历史记录结构。
- 不从页面效果图或旧设计系统总览裁切正式素材；只使用本次用户专门提供的透明素材总览作为裁切源。
- 不把现有低分辨率小墨切图强行用于新版的大幅展示位。

## 7. 已发现并纳入改版的问题

当前教材弹层底部以 60 字为上限，但真正导入和生成限制是练字帖/听写卷 30 字、生字卡片 20 字；同时仍允许多课和批量全选。改版时课文改为一次只能选择一课，移除批量全选，并显示该课的真实字数。当前 321 条课文中单课最多 16 个生字，不会超过生字卡片 20 字或其他模式 30 字的上限。

后端配额注释已经写成默认 3 份，但实际代码和根 README 仍为 8，属于实现与说明不一致。本轮以用户确认的 3 份为准统一代码、说明、前端展示和测试。若部署环境显式设置 `DAILY_SHEET_LIMIT=8`，上线时还需同步改为 3。

## 8. 已确认决策

| 编号 | 决策 | 建议默认值 |
| --- | --- | --- |
| D1 | 生成按钮是否直接放在主页面 | 是；更多设置为次入口 |
| D2 | 更多设置承载形式 | 独立页面 |
| D3 | 描红遍数范围 | 暂保留 0–8，除非产品明确缩减 |
| D4 | 生字详解/强化练习 | 本轮不做 |
| D5 | 发送到电脑 | 本轮继续使用打印链接 |
| D6 | 主配置页小墨展示 | 仅空状态/引导小尺寸使用；大图等高清素材 |

用户已确认整体 UI 开工；实现采用主页面直接生成、独立更多设置页、描红 0–8 遍，并保持本轮不新增生字详解、强化练习和真实发送到电脑能力。
